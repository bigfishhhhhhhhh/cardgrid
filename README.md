# CardGrid v5

本版在 v4 上繼續新增：

- `——價格/1——` 可選靠左／置中／靠右。
- 合併價格可再用水平、垂直滑桿微調位置。
- 背景圖片可縮放、左右裁切、上下裁切、旋轉。
- 號碼／名稱／價格／自訂文字新增「手動位置」，可用 X / Y 自由移動並跨出框框。
- 新增「自由文字」：不需要先選框框，可新增多組文字。
- 自由文字可調內容、字體、字級、顏色、透明度、X / Y 位置、旋轉，也能複製／刪除。
- 保留 v4 的 PNG 匯出，以上新元素會一起輸出。

更新方式：解壓後，把 5 個檔案上傳到 GitHub `cardgrid` repository 覆蓋舊檔，Vercel 會自動重新部署。
