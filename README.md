# CardGrid v3

本版新增：

- 每一種文字可個別設定：
  - 位置（框內 / 框外上方 / 框外下方 / 跨左上右上）
  - 字體
  - 字級
  - 顏色
  - 透明度
- 號碼可選 1 / #1 / [1] / ① / 01
- 不同尺寸卡片混排，並可設定整排上緣 / 置中 / 下緣對齊
- 連續相同價格 2 張以上自動顯示 `——價格/1——`
- 框線可開關，並設定顏色 / 粗細 / 透明度
- 框框與照片可分別設定尖角 / 圓角
- 畫布背景可用顏色或圖片
- 照片新增水平校正 / 傾斜校正 / 色溫
- 保留裁切縮放 / 左右上下裁切位置 / 旋轉 / 亮度 / 售完灰白

更新方式：將本資料夾內的 index.html、style.css、app.js、package.json、README.md 上傳到 GitHub cardgrid repository 覆蓋同名檔案；Vercel 會自動重新部署。
