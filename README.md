# CardGrid v6

新增大量商品圖工作流：
- 修正空白價格仍撐開排距的問題：只有真的有框外文字才保留空間。
- 相簿一次多選照片，自動依選取順序加入與編號。
- 一張多卡照片：OpenCV 傳統邊緣／輪廓辨識，自動抓卡片，手動新增／刪除裁切框、拖曳四角。
- 預設「原圖裁切」，不做生成式 AI 修復。
- 透視校正逐張選用，使用一般幾何 perspective transform；保留原始裁切，可恢復。
- 多卡位置自動由左到右、由上到下排序。
- 有照片卡片可拖曳重新排序（SortableJS）。
- 快速價格列表：編號 + 價格批量輸入。
- 批量共用字級／價格位置。
- 相機多卡拍攝＋可選方向感測拍正提示。
- 保留原有混搭尺寸、文字、背景、框線、自由文字、售完、PNG 匯出。

注意：多卡辨識是第一版傳統 CV，自動框可能受桌面紋理、反光、卡套邊緣影響，所以保留手動四角修正。
